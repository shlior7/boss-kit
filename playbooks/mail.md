# Boss mail commands (BOSS-template.md section 13)

The commands behind section 13. The rules stay in the template; where this file and the template differ, the template wins. Read it the first time you send or handle mail in a session.

- `boss-mail send --to <project|boss-id> --kind question|request|fyi --subject "..." [--body "..."]`, then `inbox`, `read ID`, `reply ID`, `done ID`.
- The pane shows "mail N ↗", and while mail is unread every prompt carries one line naming it.
- A message is a file in the target boss's inbox. Addressed to a project, it reaches every live boss of that project.
